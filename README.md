# 디지털 교과서 및 문제집 템플릿 (Start_copy)

이 템플릿은 수학 디지털 교과서, 학습지, 기말고사/모의고사 대비 웹사이트를 빠르고 오류 없이 제작하기 위한 원클릭 스타터 팩입니다.

## 📁 폴더 구조

- **.github/**: GitHub CI/CD 자동화 파일 (자동 배포 및 수식 검증)
- **raw/**: 원본 학습 데이터 보관 폴더
- **vault/**: 가공된 Markdown 학습 데이터 보관 폴더 (Obsidian 호환)
- **scripts/**: 수학 수식 검증 도구 (`check-formula.js`)
- **web/**: Astro 기반 정적 사이트 프론트엔드 코드
- **CLAUDE.ko.md**: AI 작업 가이드라인 (에이전트 준수 규칙)

## 🚀 빠른 시작 가이드 (새 프로젝트 생성)

1. 터미널을 엽니다.
2. `Start_copy` 폴더로 이동합니다.
3. `./setup_new_book.sh`를 실행하여 새 프로젝트 폴더를 생성합니다.
4. 생성된 프로젝트의 `web` 폴더로 이동하여 패키지를 설치하고 개발 서버를 켭니다:
   ```bash
   cd <생성한_폴더_이름>/web
   npm install
   npm run dev
   ```
